# To-Do Manager

A small React application that provides basic task management.

## Features

- Add a task
- View all tasks
- Mark a task as completed or pending
- Delete a task
- Filter tasks by All, Pending, and Completed
- Save tasks in browser LocalStorage

## Requirements

- Node.js (LTS version recommended)
- npm

## Run locally

1. Open a terminal in the `todo-manager` folder.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually http://localhost:5173).

## Current limitations

This is an intentionally small starting application. It does not currently support task editing, priorities, due dates, reminders, categories, user accounts, or reporting.
